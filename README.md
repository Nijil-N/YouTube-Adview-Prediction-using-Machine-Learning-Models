# 🎯 YouTube Ad View Prediction (Regression)

This project focuses on predicting **YouTube ad views** using regression-based machine learning techniques.  
The implementation is contained in a Jupyter Notebook and follows a standard supervised learning workflow.

---

## 🧠 Objective
To predict the number of ad views for YouTube videos based on engagement-related features using regression models.

---

## 🔍 Approach
- Loaded and explored the dataset  
- Performed data cleaning and preprocessing  
- Analyzed feature relationships  
- Trained and evaluated regression models  
- Compared model performance using evaluation metrics  

---

## 🤖 Models Used
- **Linear Regression**  
- **Random Forest Regressor**  

---

## 🛠️ Tools & Libraries
- **Python**  
- **NumPy**  
- **Pandas**  
- **Scikit-learn**  

---

## 📊 Evaluation Metrics
- **R² Score**  
- **Mean Squared Error (MSE)**
